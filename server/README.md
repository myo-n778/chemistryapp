# Chemistry Drill ローカルAI接続

2026-09-13。公開サービスではなく、このMac内で動かす実API接続。既存の問題取得GAS・記録・Sheetsは維持する。

## 起動

リポジトリで2つのターミナルを使う。

```sh
npm run ai:server
npm run dev
```

ブラウザで http://127.0.0.1:5173/?ai=1 を開き、問題へ回答して「AIに聞く」を開く。AIへ送信するのは説明ボタンまたは質問送信を押したときだけ。問題取得は従来のGASを使う。AI接続の試験ではGAS/保存POSTを模擬化したため、今回の結果をGAS疎通確認として扱わない。

`?aiMock=1` は従来の定型プレビュー。両方ある場合は模擬を優先する。クエリなしはAI非表示。配布ビルドはどちらのクエリでも非表示で、公開サイトを変更するには別の設定・認証・公開確認が必要。

## 秘密情報と通信

- キーはユーザーが指定・承認した `~/.local/share/chemistryapp/.env.local` の `OPENAI_API_KEY`。iCloud・Git・ブラウザ・VITE変数には置かない。
- `127.0.0.1:8787` にだけ待ち受ける。Viteの同一オリジンプロキシ経由で呼ぶ。
- POSTとJSONを要求し、Originはlocalhost/127.0.0.1の5173に限定。サーバー発行の不透明な2時間セッショントークンを照合する。トークンはReact側の学習セッション中のメモリだけで保持する。
- このトークンは当該Mac内での接続用。公開サービスの本人確認や生徒アカウント認証ではない。外部待受け・トンネル公開へそのまま変更しない。
- モデルは `gpt-5.6-luna`、推論なし、出力上限1000トークン。Responses APIの構造化出力を使う。`store:false`。会話全文のローカル永続保存は行わず、同じ問題の直近2往復だけメモリで保持する。OpenAI側の全データ保持がゼロになるという意味ではない。
- 自動再試行なし。失敗後はユーザーの「再試行する」操作が必要。

## 教材と制限

`learning/*.json` の確認済みローカルミラーから、モード別の正解・解説・条件をサーバーで復元する。ブラウザ側の問題ID・モード・分野・問題文・正解・解説・構造のSHA-256と照合し、不一致はAI欄だけ停止する。選択した答えもサーバーの既知候補と照合する。採点値は書き換えない。

教材ミラーの更新後はサーバーを再起動する。更新前のAIセッションは新しいセッションを開始し直す。シートだけ更新してミラーが古い場合は、その問題のAI支援を止める。

1問3回、1学習20回、1日30回（日本時間）。同時要求1件。サーバーで受付時に回数を予約し、エラー・切断・タイムアウトも算入する。日次の回数はMac内の `~/.local/share/chemistryapp/usage.json` に保持し、再起動で消えない。日次上限はこのアプリの要求数であり、OpenAIアカウント全体の課金上限ではない。接続確認の直接要求1回はこの集計外。

クライアント待機30秒、提供元待機25秒。中断しても提供元側の課金が必ず取り消されるわけではない。同じrequestIdを重複実行せず、処理中・完了済みを区別する。ロックファイルで同じ設定のサーバー二重起動を止める。異常終了後のロックを消す場合は、記載PIDのプロセスが終了していることを先に確認する。

## 検証

```sh
npm run test:ai
npm run build
```

10件のサーバー試験: 資料復元、履歴、Origin/セッション、資料改変、未知選択肢、入力サイズ、重複要求、回数上限、再起動後の日次上限、同時要求、タイムアウト、応答形式。実OpenAI通信はせず依存を模擬する。

全10タイプの先頭問題はChromeで実クライアントのハッシュと候補をサーバー教材に照合した。実AIは有機1問の説明・追加質問と無機1問の説明、指示改善後の有機再確認の計4応答を画面まで確認。別途短い接続確認1回あり。実接続先はこのMacのみ。公開・実iPad/Safari・全問の内容正確性・独立セキュリティ監査・利用者受入は未確認。
