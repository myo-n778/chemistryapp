# 化学AI：既存スプレッドシートを使うGAS

教材は既存の「chemistry」スプレッドシートで管理します。Code.gsは約17KBの処理コードだけです。教材の埋込み・圧縮データ・追加の教材シートはありません。

## 設定するもの

1. 新しいAI専用GASプロジェクトを作り、初期の `コード.gs` をこのフォルダの **Code.gs全文** へ置き換えて保存します。既存の成績用GASには貼り付けません。
2. 「プロジェクトの設定」→「スクリプト プロパティ」に次の2項目を登録します。

| プロパティ | 値 |
| --- | --- |
| `OPENAI_API_KEY` | 化学アプリ用のAPIキー。コード・GitHub・会話には貼り付けない |
| `CHEM_AI_ENABLED` | `true` |

3. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」で、実行ユーザー「自分」、アクセス「全員」を選びます。実行するGoogleアカウントには下記の教材シートを読む権限が必要です。Googleの認可で外部通信とスプレッドシートへのアクセスを確認します。**コードで行うシート操作は読み取りだけ**です。組織の制限で「全員」を選べない場合はそこで停止します。
4. 発行された `/exec` URLをアプリへ設定します（Codex担当）。APIキーを共有する必要はありません。

[Google公式：ウェブアプリの公開](https://developers.google.com/apps-script/guides/web)

## 既存教材の参照先

[chemistry スプレッドシート](https://docs.google.com/spreadsheets/d/1QxRAbYbN0tA3nmBgT7yL4HhnIPqW_QeFFkzGKkDLda0/edit)

| 出題タイプ | 読み取る既存シート |
| --- | --- |
| 有機①構造式→名称・②名称→構造式・③化合物分類 | compounds |
| 有機④反応・⑤反応条件 | reactions |
| 有機⑥・無機D | experiment |
| 無機A・B・C | inorganic |

- 列はヘッダー名で照合します。教材表は読み取り専用。質問ログはAI質問へ保存し、rec/userStatsの読書きはしません。
- AIへ質問したときだけ必要な教材表を読み、問題ID・分野・出題タイプに対応する1問を選びます。他の教材表を毎回まとめて読みません。
- 現行データ規模では教材キャッシュを設けず、その都度読み取ります。既存列の教材更新にGASの再生成・再デプロイは不要です。列構成や出題タイプの仕様変更時はコード側の対応が必要です。
- 画面の問題文・正解・解説・構造式をSHA-256で照合します。画面が古い教材を保持している場合はAIへ送らず停止します。問題を読み込み直して一致させてください。
- 通信上の `bankVersion=sheets-v1` はAPI形式の版です。教材全体の版を意味しません。教材一致は各問題の署名で確認します。
- シート欠損・列異常・重複ID・不正な構造式JSON・アクセス失敗時は、ローカルの古い教材へ切り替えず、AI問い合わせを停止します。
- 1表5万セルを超える場合は取得を停止します。現在の教材表はこの範囲内です。

## 利用制限と秘密情報

- 誰でも利用可能。氏名・学習者ID・成績はOpenAIへ送りません。
- 1問3回・匿名セッション20回・日本時間で全利用者合計1日30回。Script PropertiesとScriptLockで呼出し前に予約し、失敗も利用回数に含めます。新しいセッションでも全体の日次上限は維持します。
- 匿名セッションは2時間、開始は全体で毎分10件、同時保管60件。個人単位の認証ではありません。
- 同一requestIdの重複実行を防ぎ、自動再試行しません。同時AI処理は全体1件、異常終了時の処理予約は7分で切れます。
- 同じ問題の直近2往復をキャッシュします。教材署名が変わった場合は古い履歴を使いません。キャッシュが消えた場合は履歴なしで回答します。
- 画面の待機は30秒ですが、ブラウザからGASのUrlFetchを中止できません。GAS側が処理を続ける場合も予約回数を維持します。
- `CHEM_AI_ENABLED=false` で新規AI受付を停止できます。実行中の外部呼出しは中断しません。回数管理の `CHEM_AI_*` プロパティを手動削除しないでください。

## アプリへの接続と公開

`src/config/aiTutor.ts` またはビルド時の `VITE_GAS_URL_AI` にAI専用GASのURLを設定します。現在は公開URLを設定済みです。既存成績用GASのURLは変更しません。

クライアントはtext/plainのPOSTでJSONを送り、GASはe.postData.contentsを読みます。ContentServiceのリダイレクトをブラウザが追跡します。[Google公式](https://developers.google.com/apps-script/guides/content#redirects)

GAS配置・公開URLと実解説は確認済み。実iPad/Safari・独立セキュリティ検証は未確認です。以前の圧縮版・巨大JSON版は使用せず、今回の小さいCode.gsを使います。

## 開発用の再生成・検査

```bash
npm run ai:gas:build
npm run test:ai:gas
npm run test:ai
```

生成元は `tutor.template.js`、`sheets-source.js`、`question-log.js` とサーバー共通の教材変換・AI指示です。教材JSONをGASへ取り込む生成処理は廃止しました。通常の教材編集は上の既存シートで行います。

## 2026-09-16 質問の表記と利用ログ（現行）

アプリ内の利用者向けAI/OpenAI表記を撤去し、入口は「質問する」。学習サポートの説明行も削除。プレビュー・エラー文も解説の表現に統一。分野別・通算の表示回数、出題・採点・既存の成績保存、利用上限は維持。

解説を画面へ表示した後、専用GASへoperation=logを送り、既存chemistryの「AI質問」（sheetId=9162026）に日時・ユーザー名・問題・質問・解答の5列を記録。日時は日本時間、yyyy/MM/dd HH:mm。問題・解答はクライアント任意値でなく生成時の正本とGASの保存済み応答を使う。定型操作はボタンの意味、自由質問は入力文を記録。ユーザー名は表示開始時の利用者プロフィールから保持し、記録要求にだけ送り、OpenAI要求には含めない。本人認証された氏名ではない。

回答生成失敗・表示前中断・再開閉・操作プレビューでは記録しない。記録の失敗は回答を残して通知し、「記録を再試行」で記録だけを再送。自動再試行なし。画面を移動しても開始済み記録要求は続くが、ページ終了時の確実な保存は保証しない。再試行は匿名セッションの有効期限2時間内。記録行をScript Propertiesで予約し、同一requestIdの再送で行や回答生成を増やさない。予約後の失敗は空行を残す場合がある。記録中に行を並べ替え・削除すると再試行を拒否する場合がある。B:Eは文字列、数式として実行しない。過去ログは遡及生成しない。ローカルNode版はSheets記録の対象外。

本番実体の確認により、同一Apps Scriptプロジェクトにunify.gsとopenai.gsが存在し、公開版が別であることを確認。今回はopenai.gsと解説用URLのバージョン29だけ更新し、unify.gsと既存問題・成績用デプロイは変更しない。既存診断・認可ヘルパーは保持。今後も重複するdoGet/doPostのあるプロジェクトへ無確認で統合版を上書きしない。
