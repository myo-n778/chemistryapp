# GASの外部通信を1回診断する

現在のAI用GAS（新しいURLを発行したプロジェクト）で行います。別プロジェクトは作りません。

1. 左側の「エディタ」を開き、今のコードの末尾へ diagnose.gs の内容だけを追加して保存します。
2. 上部の実行する関数の一覧で diagnoseOpenAI を選び、「実行」を1回押します。
3. Googleの権限確認が出た場合は内容を確認して認可します。
4. 「実行ログ」の AI有効化 / APIキー設定 / OpenAI接続 または 接続例外 を確認します。

HTTP 200なら認証付きGET通信は成功しています。これは説明生成APIの成功とは別です。HTTP 401等なら認証などの応答を判別できます。接続例外では具体的なGoogle側例外を確認できます。

この関数は説明生成やシート変更を行いません。APIキーそのものも表示しません。エディタで実行する診断なので、この関数を追加しただけでウェブアプリを再デプロイする必要はありません。

ローカルでは模擬サービスでキー非表示・HTTPステータス・例外表示を検査。実GASでの実行は利用者による確認待ちです。診断後は追加した関数を削除しても本体の動作に影響しません。
